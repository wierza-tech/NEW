# A simple automation script
* Makes a zip file from old files
* Deletes old zip files
* Deletes empty directories and files

# Requirements
* Linux
* Bash (Shell)

# Instructions
1. Put the script in a safe place
2. Change Logs and Zips paths, e.g., /home/user/var/log 
3. If you want, add a cron
4. Modify the age of files to be zipped to your liking
